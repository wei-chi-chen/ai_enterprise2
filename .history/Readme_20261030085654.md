## 繁體中文說明 (Traditional Chinese)

### 一、 專案定位與核心理念

**Local Omnipotent Autonomous AI Enterprise v4.0** 是一套 100% 離線運行、具備**「貪婪記憶體裝箱調度（Greedy Memory Packing）」**與**「大模型拆解、全模型並行分治（Map-Reduce Multi-Model Concurrency）」**能力的次世代自主研發與內容生產中樞。

與傳統單一對話工具或需要人工手動分類任務的腳本不同，本系統旨在實現**「本地端的雲端級自主 AI 叢集」**：
1. **全能意圖自主路由（Zero-Classification Omnipotence）**：使用者無需手動勾選任務類型，只需輸入一句話或上傳任意附件（圖片、CSV、Excel、程式碼），總架構師模型會自主判斷並動態組合所需執行管線（多模態視覺解析、自動化資料清理、自主素材合成、HTML5 互動遊戲多輪演化、多檔案軟體工程專案、或深度研究報告）。
2. **貪婪式記憶體填滿與全模型調度（Greedy Memory Packing）**：系統即時掃描本機所有已下載之 Ollama 模型（排除純向量模型外全數納編）。在設定的硬體記憶體預算（預設 40.0 GB，可隨時於前端動態修改）內，自動計算並同時拉起最多達 8 個不同模型槽位並行推理，榨乾本機每一分算力。
3. **程序化無中生有素材鍛造（Autonomous Asset Forge）**：當執行遊戲開發或視覺專案遇到缺少美術圖示與音效時，系統內建的 `AutonomousAssetForge` 會自動合成透明背景像素精靈圖（`.png` 角色、防禦塔主堡、砲台、金幣）與數學波形合成音效（`.wav` 雷射、爆炸、升級音效），實現 100% 零外部依賴生成。
4. **長時間無損運行與動態干預（Live Feedback & Hot-Pause）**：支援真實物理時鐘（Wall-Clock Time）計時、斷點自動恢復續跑、隨時注入新意見（階段完成後自動讀取整併）、以及「暫停 $\to$ 動態調整記憶體上限 $\to$ 原地無損繼續」的完整生命週期控制。

### 二、 系統核心架構與四大實體專區

系統延續並擴充標準企業級工作區結構（位於 `enterprise_workspace/` 下）：

```text
Project_Root/
├── config.py                       # 全域路徑、預設 40GB 記憶體預算與狀態檔初始化
├── main.py                         # CLI 啟動台（自動注入 Ollama 並行環境變數）與重置工具
├── daemon.py                       # 全能排程核心：自主路由、Map-Reduce 並行分治、TDD 升級迴圈
├── requirements.txt                # Python 依賴套件清單
├── core/
│   └── model_pool.py               # 動態模型池：即時掃描 /api/tags、/api/ps 同步、貪婪裝箱排程器
├── generators/
│   └── asset_forge.py              # 自主素材生成引擎：程序化合成 2D PNG 精靈圖與 WAV 遊戲音效
├── execution/
│   └── sandbox_runner.py           # 安全執行沙盒：Python AST 語法防禦、子行程測試與 HTML5 遊戲檢驗
├── ui/
│   └── app.py                      # FastAPI + WebSocket 即時雙語監控台、試玩預覽與控制 API
└── enterprise_workspace/           # 四大企業核心專區
    ├── 01_staff/                   # 員工與硬體配置區 (staff_roster.json, employee_status.json)
    ├── 02_tasks/                   # 任務佇列區 (task_backlog.json, daemon_control.json, feedback_queue/, uploads/)
    ├── 03_delivery/                # 正式成果交付區 (projects/, games/, cleaned_data/, reports/, source_code/)
    └── 04_history/                 # 組織記憶與歷史區 (lessons_learned.json, failure_audits/, timeline_logs/)
